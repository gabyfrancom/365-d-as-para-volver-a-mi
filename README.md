# 365 días para volver a mí

App móvil (PWA instalable en Android e iOS) basada en un libro de introspección y crecimiento personal.

Cada día muestra la reflexión correspondiente según la fecha del dispositivo, con registro emocional (emoción, sensación corporal, energía) y espacio de escritura libre guardado localmente. Incluye calendario interactivo, prólogos y epílogos de cada mes, símbolos con su significado y racha de días escritos. Diseño sakura inspirado en la portada. Funciona sin conexión.

## Instalación en el móvil

- **Android:** abre la URL en Chrome → menú ⋮ → *Instalar app*
- **iPhone:** abre la URL en Safari → Compartir → *Añadir a pantalla de inicio*

## Tecnologías

HTML · CSS · JavaScript · PWA (Service Worker + Manifest)

## Novedades

- Modo claro / oscuro 🌓
- Formato de página tipo libro
- Prólogo y epílogo de cada mes
- Apartado de Lenguaje simbólico
- Fondo con fotografía real de flores de sakura (Unsplash)
- Botón Guardar en degradado lila-sakura con brillo animado
- Respiración consciente guiada (círculo animado inhala/exhala)
- Notificaciones locales 9:00 y 21:00 si falta la frase o la respiración
